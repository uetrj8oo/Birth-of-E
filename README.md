# ĐỘI EVENT UIT - WEBSITE BỐC THĂM LỜI CHÚC SINH NHẬT 🎉

Dự án website bốc thăm ngẫu nhiên đồng đội và gửi lời chúc sinh nhật dành riêng cho thành viên **Đội Sự Kiện (Đội Event) - Trường Đại học Công nghệ Thông tin (ĐHQG-HCM)**.

## 🚀 Khởi chạy nhanh
- Mở trực tiếp file `index.html` trong trình duyệt.
- Hoặc chạy `open-web.bat`.

## 📂 Cấu trúc thư mục
- `index.html`: Giao diện chính của website.
- `style.css`: Bộ quy chuẩn giao diện chủ đề Vàng Chanh Đội Event, phong cách Neo-Pop sinh viên.
- `app.js`: Xử lý thuật toán bốc thăm ngẫu nhiên, kết nối dữ liệu, và Cổng Quản trị viên.
- `data/members.js`: Danh sách 27 thành viên chính thức thuộc Ban Sự kiện và Ban Truyền thông.
- `google-apps-script.js`: Mã nguồn kết nối Google Sheets tự động dành cho Quản trị viên.
- `HUONG_DAN_SU_DUNG.md`: Hướng dẫn chi tiết từng bước sử dụng và deploy public lên mạng miễn phí.
- `assets/`: Chứa logo chính thức Đội Event - UIT, hình ảnh và font chữ.
